one_green table — Inhalte bearbeiten

Kein Programmieren nötig · exportiert content.json

So funktioniert's

  1. Felder unten ausfüllen oder ändern (Texte, Öffnungszeiten, Bewertungen, ...).
  2. Ganz unten auf „content.json speichern" klicken — du bekommst eine Datei namens content.json.
  3. Diese Datei im Website-Ordner hochladen und die alte content.json damit ersetzen.
  4. Die Website lädt die neuen Inhalte automatisch beim nächsten Aufruf — kein weiterer Schritt nötig.
